AGE CALCULATOR
==============

This is a simple age calculator made in Python. You enter your date of birth
and it tells your age in years, months and days.

I made this project while learning Python as a BCA 1st year student.


WHAT I USED
-----------
- Python
- datetime module
- Functions (def)
- if and else conditions


HOW IT WORKS
------------
1. The program asks for your date of birth in dd/mm/yyyy format.
2. It takes today's date using date.today().
3. Functions calculate the difference in years, months and days.
4. The age is printed on the screen.


HOW TO RUN
----------
1. Install Python on your computer.
2. Download age_calculator.py
3. Open the terminal and run:

   python age_calculator.py

4. Type your date of birth when asked:

   Enter your date of birth in (dd/mm/yyyy): 15/08/2005


EXAMPLE OUTPUT
--------------
21 year  3 month  25 day
